PRUEBAS AUTOMÁTICAS DEL PROYECTO GASTOS

Ejecutar desde la raíz del proyecto, uno por uno:

node tests/pruebas-logica.mjs
node tests/pruebas-etapa-4.mjs
node tests/pruebas-interfaz-etapa-4-1.mjs
node tests/pruebas-etapa-5.mjs
node tests/pruebas-interfaz-etapa-5.mjs
node tests/pruebas-interfaz-etapa-6.mjs
node tests/pruebas-interfaz-etapa-6-1.mjs
node tests/pruebas-etapa-7.mjs

Las pruebas no necesitan conectarse a Firebase ni modifican datos reales. Comprueban validaciones y cálculos, filtros, períodos, agrupaciones, administración y visibilidad de categorías, estructura HTML, selectores de JavaScript, compatibilidad de gastos históricos y orden de las secciones CSS.

Después de ejecutarlas, iniciá el servidor habitual con npm run dev y seguí documentacion/ETAPA_7_AJUSTES_CATEGORIAS_E_INGRESOS.md para comprobar la integración real en el navegador.
