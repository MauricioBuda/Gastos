PRUEBAS AUTOMÁTICAS DEL PROYECTO GASTOS

Ejecutar desde la raíz del proyecto, uno por uno:

node tests/pruebas-logica.mjs
node tests/pruebas-etapa-4.mjs
node tests/pruebas-interfaz-etapa-4-1.mjs
node tests/pruebas-etapa-5.mjs
node tests/pruebas-interfaz-etapa-5.mjs
node tests/pruebas-interfaz-etapa-6.mjs
node tests/pruebas-interfaz-etapa-6-1.mjs

Las pruebas no necesitan conectarse a Firebase ni modifican datos reales. Comprueban funciones de validación y cálculo, filtros, períodos, agrupaciones, administración de categorías y medios de pago, protección de opciones fijas, estructura HTML, selectores de JavaScript y orden de las secciones CSS.

Después de ejecutarlas, iniciá el servidor habitual con npm run dev y seguí documentacion/ETAPA_6_ADMINISTRACION_CATALOGOS.md para comprobar la integración real en el navegador.
